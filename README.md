## Upload these files

Upload everything in this folder to the root of the repository:

- `index.html`
- `styles.css`
- `script.js`
- `profile.jpg`
- `resume.pdf` (add your final resume PDF)

## Enable GitHub Pages

If GitHub does not publish it automatically:

1. Repository → **Settings**
2. **Pages**
3. Source → **Deploy from a branch**
4. Branch → **main**
5. Folder → **/(root)**
6. Save
